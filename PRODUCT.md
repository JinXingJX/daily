# Product

## Register

product

## Users

Developers and agent builders using a local desktop workspace to run chat sessions, configure model providers, attach screenshots, mount plugins, and orchestrate helper agents before or after a turn.

## Product Purpose

Daily is a local Electron agent lab backed by a Rust sidecar. It gives users one workbench for conversations, scoped settings, agent profiles, lifecycle hooks, plugin views and renderers, and runtime feedback. Success means users can quickly understand what is selected, what is running, which agent is bound, and where to configure the next step.

## Brand Personality

Precise, technical, decisive. The product should feel like a serious local workbench, not a generic SaaS dashboard or decorative AI chat demo.

## Anti-references

Avoid barely-visible token-only restyling, purple-blue AI gradients, glassmorphism, oversized marketing hero panels, identical card grids, floating-card clutter, and vague "modern" styling that does not improve workflow clarity.

## Design Principles

- Make state obvious: session, agent, runtime, and configuration state should be visible without hunting.
- Prefer workbench density: compact, scannable controls beat decorative whitespace.
- Use contrast for structure: navigation, editor, composer, and plugin areas should have distinct jobs and visual weight.
- Keep affordances standard: product confidence comes from predictable buttons, fields, tabs, and focus states.
- Boldness means clarity: amplify hierarchy and topology, not effects.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard focus visibility, avoid color-only state communication, respect reduced-motion preferences, and keep touch targets large enough on responsive layouts.
