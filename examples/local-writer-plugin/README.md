# Writer Lab example plugin

A minimal plugin with a hand-written view (no build step). It shows a main view that saves a draft with `storage.set`, calls `model.invoke`, and runs a configured agent with `agent.run`.

Install it from **Settings → Plugins → Install local plugin** with the absolute path to this folder, then open **Writer Lab** from the app rail. See [docs/plugin-development.md](../../docs/plugin-development.md).
